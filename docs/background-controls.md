# 后台功能开关

新增开关即时保存。升级旧配置时，新增的可选后台功能默认关闭；白屏／黑屏检测保留开启默认值。

- 日常自动化：同步游戏内托管状态与浮层。关闭后发送一次清理，停止同步和浮层定时器；不停止日常任务，仍可在桌面停止托管。
- 阴司透视：自动读取当前阴司。关闭后不自动查询；手动查询仍可用。
- 阴司区段扫描：区段扫描及成员更新总开关。关闭后停止定时调度，保留断点；已经发出的查询允许返回，不再安排后续查询。原“自动启动”选项决定会话启动行为，总开关具有优先权。
- 拍卖助手：启用助手与自动读取。关闭后停止购买定时器及状态刷新；未开启时不初始化助手。已发送的购买请求无法撤回。
- 三尸合成：自动读取库存。手动合成、手动刷新仍由用户操作触发。
- 调试信息：每五分钟运行内存诊断。关闭后不再安排内存采样。
- 全局设置：白屏／黑屏检测与重开。关闭后停止检测并取消恢复重试。
- 血月战场：总开关下，加速、挑战、隐匿标注分别遵守自己的开关；战旗探测沿用开始／停止按钮。

已有玩家信息、摸金地图、伤害采集和PVE辅助开关继续控制各自功能。摸金关闭后停止标注定时器；关闭标注后首次注入也会停止默认启动的标注。清理失败保留待清理状态，后续重试；成功后不持续发送清理请求。

基础连接、会话识别和日常调度属于运行所需控制，不属于上述可选轮询。关闭开关不能撤回已经发送到游戏的请求，也无法在游戏主线程无响应时保证立即执行远端清理。
