# 阴司透视 · 跨服战场

点击“拉取成员战报、贡献排名与Boss伤害”，读取当前角色所属阴司完整成员名单、本轮跨服战场贡献榜、Boss伤害榜及本阴司战场日志。不触发进攻、奖励领取或游戏内操作。

成员通过玩家ID关联，重名不会合并。主表默认显示全部成员，支持切换未参与/未上榜、已参与过滤，以及排序。主表隐藏Boss参与情况、玩家ID、服务器和职位；导出保留玩家ID，不导出服务器、职位和Boss参与情况。默认按当前总贡献降序，缺失值无论升序或降序均置底。

- 主表按周三、周五、周日排列，最后显示当前总贡献。周三（`roundId=2`）和周五（`roundId=4`）分别显示失败次数、击败怪群次数、击败玩家次数、获取贡献。仅普通怪群攻击失败（`isWin=false`）计入失败；攻击其他阴司玩家失败和Boss失败不计入。击败怪群与击败玩家分别只计明确胜利的记录，不按攻击消耗折算。
- 每日获取贡献累加该日战报的服务端 `point`（魂魄），包含记录中已知的失败所得积分。缺失积分不补零；已知积分之和显示为下限。缺少胜负不算失败或击败，明细显示未知；分页或胜负未完整时，次数显示“≥”作为下限，完整空日志才表示零次。成员通过发起战斗的玩家ID关联，重名不会合并。
- 周日显示Boss伤害、排名、预估获取贡献。伤害按“万／亿”显示，悬停可查看原始数值；所有数值列按原始数字排序，包含玩家ID、次数、贡献、排名及带“≥”的下限，不按显示文本排序。
- Boss参与依据排名、伤害、当前已同步战场角色的Boss次数或Boss日志确认。榜外且没有其他证据的成员显示待确认，不把未上榜直接当作未参与。伤害是游戏排行榜的最高伤害口径，并非把多次进攻伤害相加。
- 已计贡献来自游戏贡献排名接口。攻略Boss期间，按当前跨服伤害排名匹配本战场等级的`FinalDayCfg.rankReward`及`RankRewardCfg`中10035积分，单列预估Boss贡献，当前总贡献为两者之和。最终结算以游戏为准；非攻略期使用服务端贡献榜，不重复加Boss奖励。攻略期贡献或奖励档位缺失时总贡献留空。非攻略期仍显示可确定的Boss排名奖励预估，当前总贡献仅取服务端已计贡献。
- 战场日志使用原生接口的一基闭区间分页，每页100条，上限20,000条。查询期间总数改变、分页重复、提前结束或接口失败，会标为未完整。此时次数仅为已读取记录下限，不能据此认定玩家没有进攻。完全相同的独立日志不按内容去重。
- “战场日志”页保留逐条类型、角色ID、目标、胜负、魂魄、波数和原始时间戳；日志所属轮次由战场ID限定。

“导出全部成员CSV”不受界面过滤和排序影响，导出全部当前阴司成员。UTF-8 BOM方便Excel读取中文；数值保留原始精度，不导出“万/亿”简写。包含周三／周五各项统计与完整标记、周日Boss伤害／排名／预估贡献、当前总贡献，以及战场ID、快照时间、日志完整标记与已读/总条数。缺失值为空，避免与0混淆；文本字段对公式前缀进行转义。

Boss榜暂不可用时仍继续读取成员战报和贡献，并在提示中保留Boss榜失败原因。

数据来源为游戏客户端现有读取接口和配置，尚需实机核对服务器日志保留范围和Boss结算时点。接口不提供的历史记录不会被补造。
