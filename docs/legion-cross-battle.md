# 阴司透视 · 跨服战场

点击“拉取贡献排名、战场日志与Boss伤害”，读取当前角色所属阴司完整成员名单、本轮跨服战场贡献榜、Boss伤害榜及本阴司战场日志。不触发进攻、奖励领取或游戏内操作。

成员通过玩家ID关联，重名不会合并。主表默认显示全部成员，支持切换未参与/未上榜、已参与过滤，以及排序。

- 周二和周四各显示怪群进攻次数、来犯玩家进攻次数、折算次数。按客户端的星期显示逻辑，`roundId=1`是周二、`roundId=3`是周四。怪群一次计1，来犯玩家一次计2，包含胜利和失败的进攻日志；Boss记录和未知类型不计入打怪次数。
- Boss参与依据排名、伤害、当前已同步战场角色的Boss次数或Boss日志确认。榜外且没有其他证据的成员显示待确认，不把未上榜直接当作未参与。伤害是游戏排行榜的最高伤害口径，并非把多次进攻伤害相加。
- 已计贡献来自游戏贡献排名接口。攻略Boss期间，按当前跨服伤害排名匹配本战场等级的`FinalDayCfg.rankReward`及`RankRewardCfg`中10035积分，单列预估Boss贡献，当前总贡献为两者之和。最终结算以游戏为准；非攻略期使用服务端贡献榜，不重复加Boss奖励。贡献或奖励档位缺失时总贡献留空。
- 战场日志使用原生接口的一基闭区间分页，每页100条，上限20,000条。查询期间总数改变、分页重复、提前结束或接口失败，会标为未完整。此时次数仅为已读取记录下限，不能据此认定玩家没有进攻。完全相同的独立日志不按内容去重。
- “战场日志”页保留逐条类型、角色ID、目标、胜负、魂魄、波数和原始时间戳；日志所属轮次由战场ID限定。

“导出全部成员CSV”不受界面过滤和排序影响，导出全部当前阴司成员。UTF-8 BOM方便Excel读取中文；数值保留原始精度，不导出“万/亿”简写。包含战场ID、快照时间、日志完整标记与已读/总条数。缺失值为空，避免与0混淆；文本字段对公式前缀进行转义。

数据来源为游戏客户端现有读取接口和配置，尚需实机核对服务器日志保留范围和Boss结算时点。接口不提供的历史记录不会被补造。
