# 战旗升级预测

辅助左侧根节点 **战旗升级** → **拉取玩家进度并生成预测**。

读取当前连接角色的同步数据：北京时间、当前赛季、每关深渊难度完成情况、探渊券、今日扫荡次数、战旗等级与材料、三条战令轨道开通情况与已领取等级、任务状态及进度、本周兑换和礼包已购次数。费用、奖励、等级门槛、限购与血月时间取游戏当前配置。微信、抖音和应用宝复用同一读取脚本。

## 调整计划

- 截止日期默认本赛季结束，可改成例如11月28日。
- 每日扫荡总次数、每日新增星数、推进上限星数可调整。今天默认作为已完成后的余额，不重复扫荡/推星；勾选继续今天会扣掉今日已扫次数。
- 战令等级和当前级经验默认来自玩家，能改成假设起点；进阶和最高档轨道单独选择。未领取且已满足等级的奖励计为可立即领取，已领取的奖励不重复计入。
- 每周新增兑换木头与后续礼包总数默认0，按配置的每周限购、本周已购数量和商店结束日安排。仅编辑预测，不会兑换、购买或升级。
- “逐日调整”支持单日扫荡数、新增星数、额外战令目标等级、当周兑换目标、礼包购买日期。礼包总数是后续总预算，指定未来日期的礼包会先预留，不会被自动提前买完。指定战令目标等级表示假设获得额外等级，不自动计算该等级的购买费用。
- “战令任务”显示完成/待领取/已领取状态、进度及积分；可以给当前待完成任务指定日期，或填写“不计”。赛季星数、战旗等级任务仍必须满足实际门槛。周期任务的日期只覆盖当前周期，后续周期自动安排。

## 计算规则

预测先推星，再按当日星数扫荡。完美通关优先当前已解锁的高难度；每颗新增星需要一张探渊券，计入剩余数量、每日补充量与地图开放日。首通逐关逐难度计入，不能只用总星数推算首通奖励。

战令按配置中的每级经验递增，任务领奖产生经验，等级奖励产生材料，升级又能完成战旗任务，循环计算直至稳定。每天直接显示当日木头可支撑的最高等级，不限制一天一级，也不为任务预留升级次数；旧保存计划中的预留设置不再生效。每天的升级任务需要实际有可升级机会，卡木头或满级的日期不会虚加30经验。充值任务只有勾选每周充值、或计划购买礼包的金额达到任务门槛时才计入。

血月场次使用本赛季配置。参与次数任务逐场累计；行军、个人积分、复活丹任务在下一场尽早完成，免费复活按每日最多5次估算。这是完美完成假设，个人实际参赛资格、阴司晋级和资源需要自行保证，日期可编辑。

等级只按木头计算，镇旗布和铜钱视为充足，另列这两项消耗与缺口供参考。其他来源每日获得的镇旗布、铜钱只影响材料明细，不限制等级。扫荡元宝、兑换血月币和礼包金额单独显示预算，不代替游戏内实际购买资格与余额校验。未纳入来源不会自动产生收益。

“战旗解锁”列出当前已满足的等级、预测达到日以及截止日仍未达到的节点；满足等级不代表技能已升阶，祭旗铃消耗另列。

计划保存在配置文件旁的 `flag-upgrade-plans.json`，按平台、角色ID、赛季隔离。重新拉取会更新起始余额与任务状态，避免旧快照覆盖新角色；断线清空快照。不会启动后台轮询。
