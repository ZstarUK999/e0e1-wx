# 玩家详情 PVP 加成预估

详情顶部汇总 PVP增伤与PVP减免（快照属性117、118，原值除100得到百分比）。结果是加成预估，不是对战伤害倍率。

- 三尸补项：各方案常驻配置属性117+118合计的最大值，减去当前三尸方案合计，最低为0。条件触发描述不算常驻属性。
- 法器补项：各方案PVP词条合计最大值，减去当前 `magic.onUsePlan` 对应方案合计，最低为0。
- 当前八件二郎：保留属性里的脸谱贡献及套装10%加成，不扣除、不重复增加；保存或更新该玩家的二郎历史。
- 当前八件悟空：从属性总和中扣除当前八件脸谱的PVP基础属性及词条，再加入历史二郎脸谱PVP合计和套装额外10%；没有历史则加入脸谱40%–50%及套装10%，即50%–60%区间。历史中八件脸谱合计和套装加成分开保存、展示；旧历史没有独立套装字段时默认补10%。
- 空槽、混搭及不足八件的脸谱组合：逐件扣除已穿脸谱的PVP基础属性及词条，再按与悟空相同的规则补入二郎历史或50%–60%区间；空槽按0处理。缺少属性、当前方案或脸谱配置时，继续按已有数据给出预估，并列出未计入的缺失项，不阻止整体计算。

法器部分显示当前方案编号、名称，并标记当前使用的方案。

二郎历史保存在配置旁 `legion_scan.sqlite3` 的 `player_erlang_history` 表，按平台及玩家ID隔离。保存当时完整玩家快照（Map编码为 `{"__map__":[[key,value],...]}`），以及八件脸谱的配置ID、等级、品质、星级、基础属性、全部词条、套装、方案与观察到的玩家PVP属性。计算替换仅取历史脸谱贡献，绝不将整个人的PVP总值再次加入。当前穿悟空或八件二郎资料不完整时，不覆盖已有完整二郎历史。

界面展示历史二郎套装逐部位属性，历史完整快照在本地数据库保留。重启后可继续使用；微信及抖音各自独立。升级抖音静态脚本后需重新进入游戏。
