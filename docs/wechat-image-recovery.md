# 微信图像重开

使用 PyAutoGUI 和 OpenCV，模板位于 `package/plugin_manager/wechat_images/`。
模板来自用户提供的五张截图；以彩色匹配区分灰色入口和绿色选中状态。
只在唯一的微信主窗口内搜索，支持常见模板缩放比例，保留鼠标左上角紧急停止。

## 触发条件

- 顶号：沿用“顶号后自动重新打开游戏”设置及等待时间。只处理游戏原生的账号重复登录事件。
- 断线白屏／黑屏：独立于任务轮询检查。日常托管、手动日常任务或三尸合成正在运行，或最后活动在120秒内，且调试连接失败时，截图游戏客户区。至少99%像素为近白或近黑，且同一窗口连续确认至少15秒后才重开。已知顶号时不运行此分支。
- 普通网络错误、花屏、窗口缺失、最小化、非纯色画面不触发重开。一次尝试后冷却5分钟。

## 流程

1. 关闭之前检查依赖、五张图片和微信主窗口是否可识别。
2. 发送旧游戏窗口的关闭消息；15秒内未关闭则停止。不会杀微信进程。
3. 原有调试会话先重新准备 Frida 监听，然后才打开游戏。
4. 检测侧栏绿色图标；否则只点击一次灰色图标，等待绿色确认。
5. 同样确认“小程序”页绿色标签。
6. 查找游戏图片，只点击一次；等待新游戏窗口出现，再由原有流程确认大厅。
7. 挂载后处理开屏活动队列：抖音0.1.73的活动模块确认使用 `StitchSoulFirstFaceUI`，仅点击绑定到页面 `close` 的按钮。等待队列清空和大厅稳定2秒才交给功能初始化；陌生页面或未核实按钮停下等待人工处理。

断线截图写入 `logs/recovery/blank_white.png` 或 `blank_black.png`，每种仅保留最近一张。
截图和点击要求微信及游戏窗口可置前，并完整位于主屏幕内。界面改版或模板不匹配时停止并记录失败阶段。

重启前在助手内存中标记正在运行的日常自动化、三尸合成和手动狗粮自动合成。只有确认已重新打开游戏，且新会话已关闭开屏页、完成功能初始化、旧任务已收尾后，才消费一次标记从头启动。日常处理器和调度时间重置，合成重新读取库存，不重放结果未知的命令。狗粮已包含在日常托管时不另外重复启动。用户点击停止会取消相应恢复标记；助手进程退出后不保留标记。
